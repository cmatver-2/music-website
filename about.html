About BeatWave

The story behind the music platform

🎵

Project Overview

BeatWave is a responsive music web platform designed to connect independent artists with music lovers. The platform was built as an internship project to demonstrate modern web development skills using core web technologies — HTML, CSS, and JavaScript.

The project covers all fundamental concepts of front-end development: semantic HTML structure, responsive CSS layouts using Flexbox and Grid, interactive JavaScript features like an audio player, form validation, theme toggle, and animated UI.

Website Features

🎧

Audio Player

Stream music with play/pause controls. Only one song plays at a time with visual indicators.

📱

Fully Responsive

Works on all screen sizes — desktop, tablet, and mobile with a hamburger menu.

🌙

Dark/Light Theme

Toggle between dark and light themes. Your preference is saved in the browser.

🔍

Search & Filter

Search songs by name or artist. Filter by genre with one click.

❤️

Favorites

Save favorite songs that persist across browser sessions using localStorage.

✅

Form Validation

Contact form with real-time validation — email format, phone number, character limits.
